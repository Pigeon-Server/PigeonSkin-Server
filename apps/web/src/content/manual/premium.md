如果你本身已经拥有 Minecraft Java 版的官方正版账号，通过正版验证可以将你的正版身份与本站账号紧密相连。这不仅能有效证明并保护你的同名正版角色，许多站点还会为支持正版的小伙伴送上额外的积分鼓励。

## 发起验证

登录本站后前往 [用户中心](/user)，在界面中找到「正版验证」区域，点击发起验证按钮。系统会安全地将你引导至微软官方登录页面，只需登录拥有 Minecraft 正版特权的 Microsoft 账号并同意授权，完成后网页便会自动跳回本站并显示验证成果。

这项功能是否开启、具体奖励多少积分取决于当前站点的管理策略。如果在用户中心看不到对应的入口，说明本站目前暂未开启正版验证，如有疑问也可以咨询管理员了解详情。

## 查看与解除绑定

完成验证后，你随时可以在 [个人资料](/profile) 页面查看当前绑定的正版角色名称与状态。日后如果你在 Mojang 官方更改了自己的正版游戏名字，通常只需要按照页面提示重新点击一次验证按钮，即可轻松刷新绑定的最新状态。

如果未来因故需要解绑，点击解绑时请仔细阅读弹出的说明确认。请放心，正版绑定、本站创建的独立角色以及第三方账号登录是相互独立的体系；在解除某一项关联时，请确保你依然保留了至少一种能够顺利登入本站的凭据。

## 验证失败时

若在验证过程中遇到阻碍，建议先核实：当前登录的微软账号是否确实购买并拥有 Minecraft Java 版，且已经进入游戏设置过正式的角色名。如果在跳转授权页面时不慎取消，或者遇到网络连接超时报错，记录下错误信息后稍作等待再次尝试即可。

**最后需要特别提醒的是**：在网站上绑定正版身份，并不会自动替代客户端内部的皮肤加载逻辑，更不会改变目标服务器自身的认证方式。进入游戏后想要稳定展示本站皮肤，仍需按照 [客户端配置](/manual/customskinloader) 或 [外置登录指引](/manual/yggdrasil) 将客户端配置妥当哦。
