Yggdrasil 外置登录是一种非常便捷而优雅的联机认证方案。只要你的启动器支持该协议（基于 authlib-injector），就可以直接用本站的账号与密码登入启动器，并在进入游戏时直接以本站的角色身份畅玩，皮肤和披风也会自然加载，不需要额外配置皮肤模组。

> **温馨说明**：外置登录是属于社区服务器的独立身份验证服务，它并不能代替 Mojang 官方正版授权，也无法让你直接加入那些只开启了微软官方正版验证的纯正版服务器。

## 准备账号与角色

在配置启动器之前，请先确认你在本站的小准备已经就绪：
完成基础的 [邮箱与账号设置](/manual/account)，在后台创建好至少一个 [角色](/manual/players)，并为它穿好你喜欢的皮肤或披风。

如果你此前一直是通过第三方快捷方式登录，从未单独设置过站点密码，记得先到 [个人资料](/profile) 页面设置一个专属密码；如果使用的启动器支持现代网页授权流程，也可以按照启动器的指引直接跳转浏览器完成免密验证。

## 添加认证服务器

本站认证地址：

`{{site_url}}/api/yggdrasil`

在主流支持外置登录的启动器（例如 HMCL、PCL2、Prism Launcher 等）中，进入账户设置页面，找到「添加账户」→「外置登录 / 认证服务器（authlib-injector）」，将上面的完整网址复制并粘贴进去。

更贴心的是，在你的 [用户中心](/user) 页面右侧通常配有快捷配置模块，不仅能一键复制地址，甚至支持直接把卡片图标拖拽进支持该特性的启动器窗口里自动完成添加，省时又省心。

## 登录并选择角色

1. 在启动器的登录界面中，确保认证服务器切换为你刚添加的本站服务器。
2. 输入你在本站绑定的邮箱地址与站点登录密码。
3. 认证成功后，启动器会自动拉取到你在本站创建的所有角色，挑选你想出战的那一个，即可启动游戏！

安全方面多嘱咐一句：这里的登录表单是与本站通信的，请填写本站的密码，千万不要把你的 Microsoft 微软正版密码填进这里。如果在启动器登录成功后发现角色列表空空如也，别慌，回本站的角色管理页面创建好角色，再回启动器点一下刷新或者重新添加账户即可。

## 加入多人服务器

如果你打算加入好友或社区服主搭建的多人服务器，请先和服主打听一下：该服务器是否支持接入本站的外置登录。多人联机的顺畅体验依赖于客户端与服务端的认证源完全一致。

如果是服主想要为自己的服务器配置本站外置登录，可以参考 [官方项目说明](https://github.com/yushijinhun/authlib-injector) 文档，在服务端启动参数中挂载 authlib-injector 并把 API 地址指向本站。千万不要因为图省事而索性关闭服务端的正版验证（online-mode=false），开启外置登录既能保证免受假人压测骚扰，又能让大家带着漂亮的专属皮肤尽情玩耍。

## 网页与设备授权

在一些更现代的第三方启动器或辅助工具中，你可能会遇到更轻松的登录体验：它们会主动拉起浏览器跳转到本站的授权确认页，或者给你一段简短的设备代码，让你打开 [设备授权页面](/connect/device) 输入。遇到这种情况，仔细核对屏幕上的应用名称和所请求的角色权限，确认是自己发起的操作后点击同意即可。

无论何时，你都可以在本站的 [应用授权](/user/applications) 页面中查阅所有已经绑定授权的软件，随时可以撤销不再使用的旧设备。如果想深入了解授权的细节与安全须知，欢迎阅读 [应用授权手册](/manual/applications)。
