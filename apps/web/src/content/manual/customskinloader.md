CustomSkinLoader（常被大家亲切地称作 CSL，或是万用皮肤补丁）是 Minecraft 社区中最久负盛名、使用也极广的客户端皮肤模组之一。只要在客户端装好它，哪怕在普通的离线模式下，游戏也会根据你的角色名自动向本站索取你精心搭配的皮肤与披风。

## 安装前的准备

在正式折腾客户端之前，先花一分钟确认两件小事：
1. 前往本站的 [角色管理](/player)，确认已经建好了角色，而且角色名与你在启动器里使用的离线玩家名完全一致（连英文大小写都要对齐），并且已经为它穿好了皮肤或披风。
2. 确认你当前游玩的 Minecraft 版本以及所使用的 Mod 加载器（例如 Forge、Fabric 或 NeoForge），然后前往 [CustomSkinLoader 官方发布页](https://github.com/xfl03/MCCustomSkinLoader/releases) 下载对应版本的模组文件。

下载完成后，将得到的 `.jar` 文件直接放进对应游戏实例的 `mods` 文件夹中。如果你在启动器中开启了“版本隔离”（每个版本独立拥有一个文件夹），一定要记得打开对应那个版本的游戏目录，不要放错地方了哦。

## 下载本站配置

装好 Mod 之后，需要告诉 CSL 来我们这个皮肤站拿皮肤：

1. 启动一次已经装好 CSL 的游戏，来到游戏主界面后再退出。这一步是为了让 CSL 在本地自动创建好相关的配置目录结构。
2. 打开本站的 [配置生成器](/user/config) 页面。
3. 找到并下载专属的「ExtraList」配置文件。
4. 将下载到的文件，放进该游戏实例的 `.minecraft/CustomSkinLoader/ExtraList` 文件夹中。
5. 再次启动游戏，只要游戏名字与本站角色名一致，你的专属皮肤就会出现在身上啦！

![配置生成：左侧下载 ExtraList，右侧查看 CSL 与 Universal Skin Mod 配置](/manual/customskinloader.jpg)

**这里有一个非常常见的小插曲**：首次成功进入游戏后，你可能会发现刚才放进 `ExtraList` 目录里的文件突然“不见了”？别紧张，这可不是文件丢了或者被误删了，而是 CSL 在首次读取成功后，智能地将本站配置合并吸纳到了主配置文件中，属于完全正常的预期行为，不需要再去重复下载。

> **细心提醒**：`ExtraList` 是一个文件夹。下载下来的配置文件保持原有的 JSON 格式就好，千万不要把它解压、改名成纯文本或者糊里糊涂塞进 `mods` 文件夹里去。

## 手动配置与加载顺序

如果你是动手能力较强的高阶玩家，本站的配置生成器也直接把配置段落明文展示了出来，方便你手动粘贴到 CSL 的 `CustomSkinLoader.json` 主配置里。在手动修改前，建议先复制一份做个备份；同时留神保持合法的 JSON 格式与逗号闭合，并仔细核对 `loadlist` 里的地址是否正确无误。

为什么 `loadlist` 的顺序这么关键？如果你使用的游戏名字恰好与某位 Mojang 官方正版玩家重名了，加载顺序就决定了客户端先听谁的——是优先加载本站皮肤，还是优先加载正版皮肤？通常使用本站生成的配置即可确保本站材质处于优先位置。

## 其他 Mod

除了 CSL 之外，如果你使用的是 UniSkinMod（统一通行证皮肤模组），同样可以在 [配置生成器](/user/config) 中找到对应的适配参数。请注意不同模组之间的配置语法是完全不同的，不要把 CSL 的配置往别的模组里套用。

如果进游戏之后依然没能看到材质，先不要灰心，多半只是目录层级或者版本小细节错位了。先确认模组列表里 CSL 是否成功加载，再对照 [游戏内加载排查](/manual/faq#section-3) 一步一步检查，通常很快就能让角色焕然一新。
