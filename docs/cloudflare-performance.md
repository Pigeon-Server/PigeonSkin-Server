# Cloudflare 性能改造与动态验证

更新日期：2026-10-27。工作区改动尚未发布，以下结果区分本地证据与线上验收。

## 目标与额度

保留业务、权限、六种语言、游戏协议和 Node 自托管。D1 是权威数据源，公开低频内容使用 KV，sitemap/robots 使用 R2 生成文件，计算与任务协调交给 SQLite DO。

D1 免费额度为账户每日读取 500 万行、写入 10 万行；5 万行是此前设定的后台预算目标，并非平台总额度。额度、索引和触发器的计量以绑定 meta 和线上统计为准。

来源：[D1 价格](https://developers.cloudflare.com/d1/platform/pricing/)、[KV 价格](https://developers.cloudflare.com/kv/platform/pricing/)、[KV 一致性](https://developers.cloudflare.com/kv/concepts/how-kv-works/)、[Workers AI 价格](https://developers.cloudflare.com/workers-ai/platform/pricing/)。

## 已实现的结构

| 领域 | 数据与缓存 | 运行路径 |
| --- | --- | --- |
| 材质列表、详情、分类数量 | D1、texture_counts | 去掉无语言译表连接；先选页 ID，再按主键连接详情；数量由增量分组读取 |
| 后台统计、用户主页 | site_stats、daily_stats、texture_counts | 业务写入触发器同步维护；滚动日期首日保留有索引的边界查询 |
| 运行配置、公开设置 | settings_snapshots；内存；公开 KV | 原始设置每语言一行；公开命中跳过完整配置与认证初始化 |
| 手册、翻译、公开协议与 Live2D 配置 | 内存、KV、D1 回退 | 发布版本校验；管理员读取最新 D1；六语言回退共用源快照 |
| sitemap、分片、robots | R2 文件与发布清单 | GET/HEAD 直接读 R2；后台 DO 合并重建；正文写完后切换清单 |
| 通知 | 用户私有 notification_counts | 轮询只取未读数量；展开才读正文；隐藏页停止；多标签页共享摘要与锁 |
| AI | ai_runtime_state、ai_jobs、Workloads DO | 未启用或无可用模型时不认领；Workers AI 4006 持久暂停到 UTC 次日 |
| 日额度与后台维护 | KV 预算快照、DO、索引 | 70% 暂停非关键后台，85% 限制昂贵请求；实际 D1 日限额错误熔断 |
| 运行记录 | SQLite DO；无绑定时保留 Node D1 回退 | 保留最近 50 条；正常 Cloudflare 路径不写业务 D1 监测记录 |
| 图片、密码、Live2D | Workloads DO、R2 | PNG 校验和净化、图片流式解压与编码；图片计算串行；密码计算独立；模型文件有界批量写入 |
| 清理 | D1 索引 | 拆分 OR；每批 200、最多 10 个非空批次；按小时轮换起点 |

新增表结构与索引在 SQLite、PostgreSQL、MySQL 三份迁移中同步。MySQL 用户/材质删除显式执行相关子表操作，使汇总触发器不被外键级联绕过。

## 动态采样

诊断环境使用隔离 Miniflare/workerd、D1、R2、KV、SQLite DO、Queues 和真实前端产物。全部用户、会话和材质均为人工数据；外部 AI、邮件、OAuth 等使用本地失败响应，不向外部发送业务数据。

追踪原生 D1 session 的发送方法，覆盖 first/all/raw/batch 返回的读写计量。日志记录 HTTP/任务、SQL 文本指纹、次数、耗时和成功状态，不记录绑定参数。SQL 行数来自本地绑定；本地耗时不是 Cloudflare CPU 计费。

基础组：4,000 用户、1,200 材质、150 译文。扩大组乘十。相同时间戳和共享哈希用于暴露导入数据的连接、排序与引用检查放大。

每轮 30 分钟：冷启动 5 分钟、正常访问 10 分钟、闲置 10 分钟、并发 5 分钟。固定 tick 版本按 120 个预定时间槽执行，避免响应速度改变阶段边界与请求数量。

### 已完成的首轮对照

| 规模 | 改造前 HTTP / SQL / 读行 | 第一轮优化 HTTP / SQL / 读行 |
| --- | --- | --- |
| 基础 | 897 / 1,854 / 5,286,228 | 897 / 2,413 / 33,361 |
| 十倍 | 897 / 1,854 / 431,680,083 | 897 / 2,420 / 169,450 |

两轮均零 HTTP 失败。改造后写入由 1,804 增至 3,916 行，包含汇总、缓存版本与索引维护的额外成本。

第一轮剩余热点为 sitemap：7 次查询读取 16,142 / 152,222 行。此后已改为 R2 发布文件，并增加覆盖排序索引及独立 SEO 版本；likes 更新不提升 sitemap 版本。

### 固定序列对照

| 规模 | 改造前请求 / SQL / 读行 / 写行 | 改造后请求 / SQL / 读行 / 写行 |
| --- | --- | --- |
| 基础 | 916 / 1,866 / 5,474,599 / 1,804 | 916 / 2,261 / 16,223 / 4,062 |
| 十倍 | 916 / 1,871 / 448,142,843 / 1,804 | 916 / 2,270 / 25,973 / 4,062 |

两组均无请求失败。写入增加包含初始化、增量汇总、版本和索引维护，不能只比较读行。sitemap 与 robots 的请求阶段读取 R2，不查询 D1；公开材质目录在数据版本变化时由后台生成并复用。改造后两组各有 83 次材质列表请求，按请求关联的 D1 读行中位数为 82，最大值 767；唯一超过 500 行的请求触发了官方目录首次初始化，列表本身的三个查询合计 82 行。此结果不覆盖任意深分页及复杂搜索。

| --- | ---: | ---: | --- |
| 材质列表 | 8,026 | 8,028 | 83 次列表、首次官方目录初始化 |
| 缓存发布器 alarm | 1,245 | 10,965 | 首次 R2 公开材质目录扫描随数据量增长 |

表中为整轮累计值，包含相应路径的初始化或后台工作，不等同单次页面读取。各 SQL 指纹、执行次数与读写行数见对应 summary 和 SQL NDJSON。

额外业务旅程覆盖注册登录、并发初始化和旧账号合并、评论、工单、投票、邮件失败重试、AI 4006 暂停和手动恢复、退出后的权限检查。每组 60 次请求均无失败，分别读取 3,337 和 3,336 行。另一次 120 秒压缩采样中，公开内容 KV 读取 253 次、命中 239 次；该比例不包含内存命中，不能代表整体缓存命中率。

原始产物位于 reports/cloudflare/baseline-matched、final-catalog、journey-validate 和 cache-sample。不同请求数量的轮次不能直接当作完全相同序列比较。

### 24 小时空闲成本

原模拟发现：
- task_runs 每次追加后扫描保留集合，累计约 4,800 行；
- 搜索配置反复扫描原 settings，累计 1,992 行；
- 首次 sitemap 发布读取 1,080 / 10,800 条公开材质。

修复后使用单调虚拟时钟，执行 1,440 次分钟派发、24 次小时派发，并逐小时显式触发公开缓存、sitemap、TextureSanitizer、OfficialResourceUpdater 的 alarm。R2 预热与持续空闲分开记录：

| 规模 | 预热读行 | 空闲读行 | 空闲写行 | 请求失败 |
| --- | ---: | ---: | ---: | ---: |
| 基础 | 1,103 | 2,886 | 2 | 0 |
| 十倍 | 10,823 | 2,886 | 2 | 0 |

产物：reports/cloudflare/idle-separated。其中每分钟读取配置快照累计 1,439 行。该组关闭 AI/官方自动同步且无待净化材质；它验证空闲派发与空 alarm，不代表启用任务的消费成本或队列失败重试总成本。AI 日限额、DO 配额暂停和队列业务通过专项另行验证。

## 确认缺陷与处理

| 缺陷 | 动态/代码证据 | 结果 |
| --- | --- | --- |
| LEFT JOIN 翻译表 ON 1=0 | 生产 8 次累计 1,262,816 读行；本地随数据量异常放大 | 无语言时删除连接 |
| 排序让第二阶段仍扫描整类材质 | 本地十倍组详情查询单次 10,824 行 | 主键读取后按选页顺序组装 |
| 引用判断 OR 缺括号 | 改/删私有材质时扫描全表 | 修正 AND/OR 范围，保留游戏可加载语义 |
| 官方衣柜、每日首日统计缺匹配索引 | 本地每次读取万级记录 | 补齐 revision 与 created_at 索引 |
| 配置按多行重复加载 | 生产两类设置查询约 102 万行 | 单行快照、统一失效与并发写条件 |
| AI 日配额后半小时重扫 | 后台旧派发逻辑 | 持久暂停；模型/凭据/开关变更与手动重置恢复 |
| REST AI 4006 被丢弃 | Clef 非 2xx 只保留状态码 | 保留错误 code；专项验证后续不读 ai_jobs |
| DO alarm 不受配额治理 | 审查发现净化游标会在额度失败时推进 | 配额错误不计业务失败、不推进游标、次日恢复 |
| 监测日志反过来读取业务库 | 空闲 SQL 排名首位 | Cloudflare 运行记录转 DO |
| 普通请求内重复执行 PNG 结构和 CRC 校验 | 上传、替换、类型编辑和管理导入直接执行完整校验 | 调度到计算 DO；无绑定环境保留原有 Node 路径 |
| MySQL 触发器/INSERT SELECT 冲突 | 实际 MySQL 1442 与 PG conflict 语法错误 | 独立写门闩、方言重写、真实跨库验证 |

## 验证记录

- 数据库：48 项通过；新增真实 SQLite 快照、事务回滚、汇总与索引用例。
- Node：215 项通过，服务端构建通过；跨 DO 的并发事务与普通写入、回滚隔离有专项回归。
- Web：221 项通过，前端构建通过；通知组件测试覆盖隐藏页暂停、卸载、多标签页和展开加载。
- Minecraft：84 项通过，包括 128×128 高清皮肤上传校验、跨多个 IDAT 和压缩流分块边界的像素回归，以及压缩流截断与校验失败的拒绝测试。
- PostgreSQL 15 / MySQL 8.4：隔离容器内全部迁移、计数变化、所有者转移、删除级联、配置快照、AI 熔断/重置验证通过。产物 database-validation.json。
- R2：重复 GET/HEAD 无 D1、清单原子切换、私密 URL 移除、likes 不失效、域名变化和检查时间有专项回归。
- 发布器：真实 workerd 中依赖异常后仍可处理后续请求，8 个并发发布均完成；构建期间收到 sitemap 新变更时，KV 日预算不会覆盖较早的重建时间。外部网络调用不再持有原生 DO 阻塞段。
- 图片：上传、替换、管理导入和 Ygg 上传保留高清纹理尺寸支持，宽度不超过 8192 px、面积不超过 16,777,216 px；另设 16 MiB 硬文件上限和请求体上限，避免异常压缩 PNG 在解析前耗尽 Worker 内存。皮肤、披风的 Minecraft 类型与比例规则保持不变，旧版披风补边兼容保留。此前 57.4 MB 高熵样本会在 multipart 解析前被拒绝，不影响 128×128 等正常高清材质。
- 浏览器：人工账号登录真实前端；展开通知时才取正文；两标签页网络观察只请求 summary，跨页读取间隔超过 60 秒。IAB 两页都报告 visible，隐藏页由组件测试验证。
- 预览 dry-run：打包与绑定检查通过。预览及生产 D1 的远端查询均返回 7500 账户每日读取额度错误；未完成预览部署、实际 CPU/D1 计量、生产迁移和 24 小时观察。70%/85% 主动预算阈值依赖独立 Analytics token，线上尚未配置验证；实际额度错误熔断已有本地验证。
- Worker 测试按文件分四组共 440 项通过；单运行时全套出现跨请求 I/O context 异常，尚未稳定完成。使用的测试运行时最高兼容日期为 2026-03-10，生产配置为 2026-09-01，线上结果仍需独立验证。

## 模块覆盖与剩余验收

HTTP 路由、中间件、仓储/服务、前端轮询、SEO、Cron、Queues、DO、CLI/导入与三方言迁移均纳入检查范围。已执行的长采样包含访客浏览、翻页/语言、私有访问边界、登录、上传改删、衣柜与角色操作、手册改删、后台统计、协议发现/纹理/头像/预览、分钟与小时调度。

| 模块 | 动态证据 | 主要数据路径 |
| --- | --- | --- |
| 公开页面、手册、协议发现 | 30 分钟序列和 KV 样本 | 内存/KV，失效后读取 D1 快照 |
| 材质列表、详情、衣柜、角色 | 30 分钟序列及私密访问专项 | 索引选页、增量数量、用户范围查询 |
| 注册登录、评论、工单、投票 | 业务旅程和 API 测试 | D1 权威数据和权限判断 |
| 通知 | 浏览器双标签页、组件测试 | 用户汇总，展开读取正文 |
| SEO、sitemap、robots | R2 专项与 30 分钟序列 | R2 读取，后台版本驱动重建 |
| 管理设置、统计与手册 | 业务序列和跨库测试 | 设置快照、增量汇总、版本失效 |
| Cron、DO、Queues、AI | 24 小时虚拟调度、失败与限额专项 | 分批处理、配额熔断、DO 日志 |
| CLI、导入、数据库迁移 | 静态检查和三方言迁移测试 | 权威写入通过触发器维护快照和汇总 |

静态清单包含 143 个服务端模块和 291 个路由或中间件声明，具体候选路径见 reports/cloudflare/route-coverage.csv；它不是运行覆盖率报告。动态采样的请求及 SQL 关联记录位于对应轮次的 HTTP JSON 和 SQL NDJSON 文件。

注册、评论、工单/投票的非空提交、队列重试和失效令牌通过额外业务旅程验证，部分游戏完整认证流程由 API 专项覆盖，尚未全部纳入同一个 30 分钟操作混合。不能把空列表请求当作完整业务的动态验收。路由静态清单的候选查询需要与运行时 SQL 轨迹交叉核实，不能视为所有分支均已执行。

待收尾：
1. 修复或升级单运行时 Worker 测试池，完成稳定的整套回归。
2. 独立只读审查复验；修复清单关闭后再发布。
3. 线上验证硬限制在普通上传、Ygg 上传、管理导入和替换入口均生效。
4. D1 额度恢复后完成 Cloudflare 预览实际 CPU/行数、分阶段生产迁移与回滚检查、生产至少 24 小时观察。

## 复现

```sh
node tools/scripts/performance.mjs --tag=final-catalog --seconds=1800 --scales=1,10 --port=8850
node tools/scripts/performance.mjs --tag=baseline-matched --bundle=reports/cloudflare/baseline/worker.mjs --legacy=true --seconds=1800 --scales=1,10 --port=8870
node tools/scripts/performance.mjs --tag=idle-separated --idle=true --warm=true --scales=1,10 --port=8830
node tools/scripts/performance-image.mjs --bundle=reports/cloudflare/image-streaming/worker.mjs --output=maximum-image-streaming-default.json
node tools/scripts/performance-image.mjs --high-entropy --bundle=reports/cloudflare/image-streaming/worker.mjs --output=maximum-image-streaming.json
node tools/scripts/performance-databases.mjs
```

跨库脚本仅面向本任务创建的本地隔离容器端口，使用人工账户与数据；不用于生产库。采样产物存储于忽略目录，性能结论应连同 SQL NDJSON、HTTP JSON、summary 和 frozen worker 一起核验。
