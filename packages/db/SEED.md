# 数据库种子脚本

给本地开发环境加入两个虚构演示账号和角色，不导入用户材质。

## 用法

```bash
# 1. 应用迁移（若尚未应用）
npm run db:migrate:local

# 2. 生成随机密码并灌入本地 D1
npm run db:seed:local
```

## 种子内容

| 账号 | 角色 | 说明 |
|---|---|---|
| `admin@example.test` | super_admin | 演示管理员 |
| `user@example.test` | normal | 演示用户 |

密码每次随机生成，仅在成功写入本地数据库后输出到终端；重复运行会重置这两个演示账号的密码。临时 SQL 在命令结束时清理。命令固定使用 `--local`，不接受远程参数。不要将演示数据库、终端输出或迁移后的真实数据提交到仓库。

同名邮箱属于非演示账号、存在旧邮箱冲突标记，或演示角色名已被其他账号占用时，命令会拒绝写入。不要用种子命令覆盖迁移后的账号。

生产环境的首个管理员通过 `/setup` 安装向导创建，或由旧库迁移保留原管理员权限。
